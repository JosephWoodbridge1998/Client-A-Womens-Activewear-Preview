# WomenActiveWear — Client A preview

White, baby-pink and charcoal activewear demonstration by JW Growth & Design. Client-specific workspace; the Stilla master and JW homepage are unchanged.

## Run
Open index.html with styles.css and app.js beside it. No build or dependencies. Internet is required for remotely hosted demonstration photographs and Google Fonts. A static local web server is recommended for review.

## Features
Six example products; category, colour and size filtering; price sorting; product modal; mandatory size selection; in-memory shopping bag with quantity changes, removal and subtotal; non-selling checkout message; responsive layout and reduced-motion CSS. Bag state resets on refresh. No forms, analytics, payment service or order API.

## Edit
- index.html: brand messaging and sections.
- styles.css: colours and typography in :root.
- app.js: products, prices, sizes, colours, photographs and illustrations.
- Replace all example imagery and product data with approved client material before a real launch. Two shorts entries share the same demonstration image. T-shirts use original SVG illustrations, not real product photographs. No product performance claims are made.

## Preview safety
Fictional brand and prices. No payment or order processing. No personal details collected. No real delivery, returns or size policies promised. noindex,nofollow is not access control. Do not publish private client material without approval.
